# ⚙️ EduSpace Backend

Ứng dụng Backend REST API của hệ thống **EduSpace**, được phát triển dựa trên **Java 21**, **Spring Boot 4.0.6**, **Spring Security**, **JWT**, **Spring Data JPA** và **MySQL**.

👉 Để xem chi tiết tổng quan dự án, quy trình cài đặt và tài liệu API, vui lòng tham khảo [Root README.md](../README.md).
👉 Để xem chi tiết sơ đồ kiến trúc phân tầng Backend, vui lòng tham khảo [PROJECT_STRUCTURE.md](./PROJECT_STRUCTURE.md).

---

## 🚀 Các lệnh chính (Maven Commands)

| Hệ điều hành | Lệnh khởi chạy | Mô tả |
| :--- | :--- | :--- |
| **Windows** | `.\mvnw.cmd spring-boot:run` | Khởi chạy ứng dụng Spring Boot Backend |
| **Linux / macOS** | `./mvnw spring-boot:run` | Khởi chạy ứng dụng Spring Boot Backend |
| **Build WAR/JAR** | `./mvnw clean package` | Đóng gói sản phẩm |
