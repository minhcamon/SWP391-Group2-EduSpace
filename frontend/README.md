# 🎨 EduSpace Frontend

Ứng dụng Frontend của hệ thống **EduSpace**, được xây dựng bằng **React 19**, **Vite 8**, **Tailwind CSS v4** và **Shadcn UI**.

👉 Để xem toàn bộ thông tin dự án, kiến trúc hệ thống và hướng dẫn khởi chạy chi tiết, vui lòng xem tại [Root README.md](../README.md).

---

## 🚀 Các lệnh chính (Scripts)

| Lệnh | Mô tả |
| :--- | :--- |
| `npm run dev` | Khởi chạy server phát triển local với HMR tại `http://localhost:5173` |
| `npm run build` | Thống kê & đóng gói production bundle vào thư mục `dist/` |
| `npm run lint` | Kiểm tra cú pháp và quy chuẩn mã nguồn với ESLint |
| `npm run preview` | Khởi chạy xem trước bản build production cục bộ |
